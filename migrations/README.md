# Migrationsskripte

`sql/create_database.sql` enthält den aktuellen vollständigen Datenbankstand für eine frische Installation.

Die Dateien in diesem Ordner dokumentieren Entwicklungsschritte, die während der Arbeit am Projekt entstanden sind. Sie zeigen, wie eine bestehende Datenbank später erweitert werden kann. Nach einem frischen Import von `create_database.sql` müssen diese Skripte nicht zusätzlich ausgeführt werden.
